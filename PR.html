What changed

A normal browser visit to / now opens a minimal product page instead of a wall of API text. A visitor pastes a public GitHub repository, copies the generated prompt, and gives it to a coding agent.

  • The purpose and read-only/public-repo boundary are visible immediately.
  • The generated prompt teaches discovery, narrow file reads, and SHA pinning.
  • Agents keep the complete plain-text guide at /llms.txt.
  • Raw clients keep the existing root document unchanged.

  format === "html" ||
  (format !== "text" && accept.includes("text/html"));
