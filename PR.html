gitvfs endpoint semantics fixes

Branch codex/gitvfs-end-to-end-fixes · deployed to gitvfs.miryaboy.workers.dev · Worker version 64453466-0706-4483-bdf5-3dadc0f40a09

What Changed

  • File line metadata now uses one logical line-count convention across /file, /stat, /outline, HEAD /file, grep context, and ?lines=.
  • /file?lines=... past EOF returns 416 line_range_not_satisfiable instead of a phantom blank line.
  • OPTIONS preflight now returns CORS metadata before repo resolution, Durable Object access, or route execution.
  • /bash non-zero exits now return non-2xx HTTP statuses while preserving x-gitvfs-exit-code and stdout/stderr.
